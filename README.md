#  AI-Powered Document Q&A System using RAG (LangChain + FAISS + Hugging Face)

## 📌 Overview
This project implements a Retrieval-Augmented Generation (RAG) based chatbot that allows users to upload PDF or TXT documents and ask natural language questions based on their content.

The system combines document retrieval with large language models to provide accurate, context-aware answers, enabling efficient knowledge extraction from unstructured data.

---

## 🎯 Problem Statement
Organizations often deal with large volumes of unstructured documents (reports, manuals, PDFs), making it difficult to quickly extract relevant information.

Traditional keyword search is inefficient and lacks contextual understanding.

---

## 💡 Solution
This project builds an intelligent document question-answering system that:
- Understands user queries in natural language
- Retrieves relevant document chunks using vector search
- Generates accurate answers using LLMs

---

## 🚀 Key Features
- 📄 Upload PDF/TXT documents
- 🔍 Semantic search using embeddings
- 💬 Context-aware question answering
- ⚡ Fast retrieval with FAISS vector database
- 🌐 Deployed interactive web application

---

## ⚙️ System Architecture
1. Document Upload  
2. Text Chunking  
3. Embedding Generation (Hugging Face)  
4. Vector Storage (FAISS)  
5. Query Input  
6. Retrieval of Relevant Chunks  
7. Answer Generation using LLM  

---

## 📊 How It Works
- Documents are split into smaller chunks
- Each chunk is converted into vector embeddings
- User queries are also embedded
- FAISS retrieves the most relevant chunks
- LLM generates a final answer using retrieved context
